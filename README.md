GILTFALL

Drop. Push. Collect. Repeat.

A little arcade nostalgia, right in your browser.

GILTFALL is a browser-based coin pusher arcade game inspired by classic coin-dozer machines. Drop coins, watch the mechanical pusher move the pile, collect falling coins and special prizes, and see how long you can keep your balance alive.

No accounts. No backend. No real money. Just coins, physics, and a little arcade luck.

---

🎮 Play the Game

Live Demo: [GiltFall](https://giltfall.pages.dev/)

GILTFALL runs directly in your web browser. No installation or registration required.

✨ Features

- Physics-Based Gameplay – Coins interact, collide, stack, and move using a 2D physics engine.
- Arcade Coin Pusher – Drop coins onto a moving mechanical platform and collect those that fall into the tray.
- Multiple Coin Types – Gold and silver coins with different reward values.
- Special Prizes – Collect Gift Boxes, Gems, Gold Bars, and Mystery Boxes for bonus rewards.
- Progression System – Earn score, advance through levels, and face increasing difficulty.
- Combo System – Build consecutive successful drops to activate reward multipliers.
- Auto-Drop – Enable automatic coin dropping.
- Sound Effects – Procedurally generated arcade sounds using the Web Audio API.
- Persistent Progress – Your balance, score, and progression are saved locally in your browser.
- Responsive Design – Play on desktop, tablet, or mobile devices.

🕹️ How to Play

1. Start with your initial supply of coins.
2. Move the coin dropper horizontally.
3. Drop a coin onto the playing platform.
4. Watch the mechanical pusher move the pile forward.
5. Collect coins and special prizes that fall into the collection tray.
6. Manage your coin balance carefully. Every drop costs one coin.
7. Keep playing, earn rewards, and advance through the levels.

Game Over: When your spendable coin balance reaches zero, the game ends. Start a new session to play again.

GILTFALL is distributed as a single HTML file.

1. Clone this repository:
   
   git clone https://github.com/invalidcastvibe/giltfall.git

2. Open the project folder.

3. Open "index.html" in a modern web browser.

That's it!

No build process or package installation is required, provided all required dependencies are included or accessible.

☁️ Deployment

GILTFALL can be hosted using free static hosting services.

GitHub Pages

1. Push "index.html" to your GitHub repository.
2. Open the repository's Settings.
3. Navigate to Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the "main" branch and "/ (root)" directory.
6. Save your settings.

GitHub Pages will publish your game.

Cloudflare Pages

1. Log in to the Cloudflare Dashboard.

2. Navigate to Workers & Pages.

3. Select Create application and then Pages.

4. Connect your GitHub repository.

5. Select the production branch.

6. Configure the deployment:
   
   Setting| Value
   Framework preset| None
   Build command| Leave empty
   Build output directory| "/"
   Root directory| "/"

7. Deploy.

Cloudflare Pages will host the game as a static website.

💾 Save Data

GILTFALL uses your browser's localStorage to save game progress and preferences.

This means:

- Progress is saved on the current browser and device.
- No account is required.
- Clearing browser data may erase saved progress.
- Progress does not automatically synchronize across devices.
